# FAMOUS XXL — Multi-page Artist Website

A responsive, multi-page artist website built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home / artist landing page
- `about.html` — Artist profile and story
- `music.html` — Music catalogue and streaming links
- `videos.html` — On Screen preview using the supplied FAME ENTERTAINMENT logo
- `gallery.html` — Gallery using the supplied artist photographs
- `news.html` — Official updates
- `bookings.html` — Booking and professional enquiries

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser.
4. Use the navigation menu to move between the separate pages.

## Important content notes
- The FAME ENTERTAINMENT logo is used as the On Screen preview artwork; it is not a music video.
- The Music page includes platform links and selected catalogue names that should be checked and approved by the artist or management before public launch.
- No booking email or phone number has been invented. Add verified contact details when management provides them.
- The artist photos are in `assets/`. Keep the folder alongside the HTML pages.
